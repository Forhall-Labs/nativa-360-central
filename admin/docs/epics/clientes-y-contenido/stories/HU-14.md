# HU-14 — Administrar visitas del doctor

| Campo      | Valor                                                                               |
| ---------- | ----------------------------------------------------------------------------------- |
| Usuario    | Administrador o personal autorizado                                                 |
| Prioridad  | Media                                                                               |
| Riesgo     | Medio                                                                               |
| Sprint     | 6 · Clientes y contenido                                                            |
| Puntos     | 5                                                                                   |
| Requisitos | MO-27 (admin), MO-06 (landing)                                                      |
| Reglas     | RN-34, RN-35, RN-36                                                                 |
| API        | [HU-14 en el backend](../../../../../backend/docs/epics/contenido/stories/HU-14.md) |

## Historia

> **Como** administrador, **quiero** registrar, publicar, modificar y retirar
> las visitas del doctor, **para** que los clientes sepan qué días y en qué
> horario pueden consultarlo en la tienda.

## Escenarios

```gherkin
Característica: Administrar visitas del doctor

  Antecedentes:
    Dado que el administrador inició sesión en el panel

  Escenario: Positivo – registrar y publicar una visita
    Dado que el administrador está en "Visitas del doctor"
    Cuando registra al "Dr. Luis Vargas", especialidad "Medicina natural", el 22/11 de 09:00 a 12:00
    Y la marca como "confirmada"
    Entonces la visita queda publicada
    Y la landing la muestra en "Visitas del doctor"

  Escenario: Positivo – modificar el horario
    Dado que la visita del 22/11 está publicada de 09:00 a 12:00
    Cuando el administrador cambia el horario a 10:00 a 13:00
    Entonces la landing muestra el nuevo horario

  Escenario: Negativo – una visita sin confirmar no se publica
    Dado que el administrador registró una visita en estado "pendiente de confirmar"
    Cuando un cliente abre la landing
    Entonces esa visita no aparece

  Escenario: Negativo – una visita cancelada deja de anunciarse
    Dado que la visita del 22/11 está publicada
    Cuando el administrador la cancela
    Entonces la landing deja de mostrarla

  Escenario: Error – falla al guardar la visita
    Dado que la API no responde
    Cuando el administrador guarda una visita
    Entonces ve "No se pudo guardar la visita. Intentá de nuevo"
    Y los datos del formulario se conservan

  Esquema del escenario: Validación – datos de la visita
    Dado que el administrador está registrando una visita
    Cuando ingresa <dato>
    Entonces ve "<mensaje>"
    Y la visita no se guarda

    Ejemplos:
      | dato                                       | mensaje                                       |
      | hora de inicio 12:00 y hora de fin 09:00   | La hora de fin debe ser posterior al inicio   |
      | hora de inicio 09:00 y hora de fin 09:00   | La hora de fin debe ser posterior al inicio   |
      | el nombre del doctor vacío                 | El nombre del doctor es obligatorio           |
      | la especialidad vacía                      | La especialidad es obligatoria                |
      | una fecha anterior a hoy                   | La fecha de la visita no puede estar en el pasado |
```
