## Historia

> **Como** administrador, **quiero** registrar, consultar, modificar y
> deshabilitar productos, **para** que el catálogo en línea muestre siempre la
> información correcta.

## Escenarios

```gherkin
Característica: Administrar productos

  Antecedentes:
    Dado que existe la categoría "Vitaminas"
    Y que el administrador inició sesión en el panel

  Escenario: Positivo – registrar un producto
    Dado que el administrador está en "Productos"
    Cuando presiona "Nuevo producto"
    Y completa código "VIT-001", nombre "Vitamina C 1000 mg", descripción, precio ₡6 500, categoría "Vitaminas" e imagen
    Y presiona "Guardar"
    Entonces ve "Producto guardado"
    Y "Vitamina C 1000 mg" aparece activo en la lista y en el catálogo del e-commerce

  Escenario: Positivo – deshabilitar un producto
    Dado que existe el producto activo "Vitamina C 1000 mg"
    Cuando el administrador lo deshabilita y confirma la acción
    Entonces el producto queda "inactivo"
    Y deja de aparecer en el catálogo
    Pero sigue apareciendo en los pedidos que ya lo incluían

  Escenario: Negativo – el empleado no puede cambiar precios
    Dado que un empleado inició sesión
    Cuando abre el producto "Vitamina C 1000 mg"
    Entonces ve el precio pero no lo puede editar
    Y si intenta cambiarlo por otro medio, la API responde "No tenés permiso para esta acción"

  Escenario: Negativo – código de producto repetido
    Dado que ya existe un producto con código "VIT-001"
    Cuando el administrador registra otro producto con código "VIT-001"
    Entonces ve "Ya existe un producto con el código VIT-001"
    Y el producto no se guarda

  Escenario: Error – falla la carga de la imagen
    Dado que el administrador está registrando un producto
    Cuando sube la imagen y el servicio de almacenamiento no responde
    Entonces ve "No se pudo subir la imagen. Intentá de nuevo"
    Y los demás datos del formulario se conservan

  Esquema del escenario: Validación – campos del producto
    Dado que el administrador está registrando un producto
    Cuando deja el campo <campo> con el valor "<valor>" y presiona "Guardar"
    Entonces ve "<mensaje>"
    Y el producto no se guarda

    Ejemplos:
      | campo       | valor | mensaje                              |
      | nombre      |       | El nombre es obligatorio             |
      | descripción |       | La descripción es obligatoria        |
      | precio      | 0     | El precio debe ser mayor a 0         |
      | precio      | -500  | El precio debe ser mayor a 0         |
      | imagen      |       | La imagen es obligatoria             |
```
