# Épica: API de contenido

> **Como** frontend de Nativa 360 (landing, e-commerce y admin), **quiero**
> una API que publique promociones, eventos, contenido multimedia y visitas
> del doctor respetando sus fechas, **para** que el sitio muestre solo lo que
> está vigente.
