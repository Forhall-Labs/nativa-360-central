# HU-12 (API) — Consultar el historial de pedidos

| Campo     | Valor                                                                                      |
| --------- | ------------------------------------------------------------------------------------------ |
| Endpoints | `GET /admin/pedidos?estado=&desde=&hasta=&cliente=`                                        |
| Acceso    | Administrador, empleado, propietario con permisos                                          |
| Reglas    | RN-09                                                                                      |
| Frontend  | [HU-12 en el admin](../../../../../admin/docs/epics/clientes-y-contenido/stories/HU-12.md) |

## Historia

> **Como** panel de administración, **quiero** consultar el historial de
> pedidos con filtros, **para** revisar el movimiento del negocio sin
> descargar todos los pedidos.

## Escenarios

```gherkin
Característica: API del historial de pedidos

  Antecedentes:
    Dado que hay pedidos de octubre y noviembre en distintos estados
    Y que un administrador está autenticado

  Escenario: Positivo – filtrar por estado y fechas
    Cuando hace GET /admin/pedidos?estado=entregado&desde=2026-10-01&hasta=2026-10-31
    Entonces la respuesta es 200 con los pedidos entregados en octubre, paginados

  Escenario: Positivo – el precio histórico se conserva
    Dado que un pedido de octubre guardó "Omega 3" a ₡8 000 y hoy cuesta ₡9 000
    Cuando consulta ese pedido
    Entonces el detalle muestra ₡8 000

  Escenario: Negativo – no existe un endpoint para borrar pedidos
    Cuando hace DELETE /admin/pedidos/N360-0010
    Entonces la respuesta es 404 o 405
    Y el pedido sigue existiendo

  Escenario: Error – la base de datos no responde
    Dado que la base de datos no está disponible
    Cuando hace GET /admin/pedidos
    Entonces la respuesta es 503

  Esquema del escenario: Validación – filtros
    Cuando hace GET /admin/pedidos con <filtro>
    Entonces la respuesta es <codigo>

    Ejemplos:
      | filtro                                   | codigo |
      | desde=2026-10-01&hasta=2026-10-31         | 200    |
      | desde=2026-10-31&hasta=2026-10-01         | 400    |
      | desde=2026-13-01                          | 400    |
      | estado=enviado                            | 400    |
```
