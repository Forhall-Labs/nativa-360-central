# HU-11 (API) — Consultar información de clientes

| Campo     | Valor                                                                                      |
| --------- | ------------------------------------------------------------------------------------------ |
| Endpoints | `GET /admin/clientes?buscar=`, `GET /admin/clientes/:id`                                   |
| Acceso    | Administrador, empleado                                                                    |
| Reglas    | RN-26                                                                                      |
| Frontend  | [HU-11 en el admin](../../../../../admin/docs/epics/clientes-y-contenido/stories/HU-11.md) |

## Historia

> **Como** panel de administración, **quiero** consultar los clientes y sus
> pedidos en la API, **para** que el personal los atienda con su información
> a mano.

## Escenarios

```gherkin
Característica: API de clientes

  Antecedentes:
    Dado que la clienta "Ana Mora" tiene 3 pedidos

  Escenario: Positivo – buscar y ver un cliente
    Dado que un empleado está autenticado
    Cuando hace GET /admin/clientes?buscar=ana
    Y luego GET /admin/clientes/<id de Ana Mora>
    Entonces recibe sus datos de contacto y sus 3 pedidos

  Escenario: Negativo – un cliente no puede ver a otros clientes
    Dado que otro cliente está autenticado
    Cuando hace GET /admin/clientes/<id de Ana Mora>
    Entonces la respuesta es 403

  Escenario: Negativo – cliente inexistente
    Dado que un empleado está autenticado
    Cuando hace GET /admin/clientes/99999
    Entonces la respuesta es 404

  Escenario: Error – la base de datos no responde
    Dado que la base de datos no está disponible
    Cuando un empleado hace GET /admin/clientes
    Entonces la respuesta es 503

  Esquema del escenario: Validación – búsqueda
    Dado que un empleado está autenticado
    Cuando hace GET /admin/clientes?buscar=<valor>
    Entonces la respuesta es <codigo>

    Ejemplos:
      | valor                         | codigo                          |
      | ana                           | 200 con "Ana Mora"              |
      | 88887777                      | 200 con "Ana Mora"              |
      | (vacío)                       | 200 con la lista paginada       |
      | (más de 100 caracteres)       | 400                             |
```
