# HU-03 (API) — Buscar y filtrar productos

| Campo     | Valor                                                                          |
| --------- | ------------------------------------------------------------------------------ |
| Endpoints | `GET /productos?buscar=&categoria=`, `GET /categorias`                         |
| Acceso    | Público                                                                        |
| Reglas    | RN-02                                                                          |
| Frontend  | [HU-03 en el e-com](../../../../../e-com/docs/epics/catalogo/stories/HU-03.md) |

## Historia

> **Como** e-commerce de Nativa 360, **quiero** buscar productos por texto y
> filtrarlos por categoría desde la API, **para** que el cliente encuentre lo
> que necesita sin cargar todo el catálogo.

## Escenarios

```gherkin
Característica: API de búsqueda y filtros

  Antecedentes:
    Dado que existen productos activos en las categorías "Vitaminas" y "Tés"

  Escenario: Positivo – buscar por texto
    Cuando se hace GET /productos?buscar=magnesio
    Entonces la respuesta es 200 con los productos activos cuyo nombre o descripción contiene "magnesio"

  Escenario: Positivo – búsqueda sin tildes ni mayúsculas
    Cuando se hace GET /productos?buscar=TE
    Entonces la respuesta incluye los productos que contienen "té"

  Escenario: Positivo – listar categorías
    Cuando se hace GET /categorias
    Entonces la respuesta es 200 con las categorías activas

  Escenario: Negativo – sin coincidencias
    Cuando se hace GET /productos?buscar=xyz123
    Entonces la respuesta es 200 con una lista vacía

  Escenario: Error – la base de datos no responde
    Dado que la base de datos no está disponible
    Cuando se hace GET /productos?buscar=vitamina
    Entonces la respuesta es 503 con el formato de error estándar

  Esquema del escenario: Validación – parámetros de búsqueda
    Cuando se hace GET /productos con <parametro>
    Entonces la respuesta es <codigo>

    Ejemplos:
      | parametro                              | codigo                        |
      | buscar vacío                           | 200 con el catálogo completo  |
      | buscar de más de 100 caracteres        | 400                           |
      | categoria con un identificador inexistente | 200 con una lista vacía   |
      | categoria con un valor que no es un identificador | 400                |
```
