# HU-02 (API) — Consultar catálogo de productos

| Campo     | Valor                                                                          |
| --------- | ------------------------------------------------------------------------------ |
| Endpoints | `GET /productos?page=&limit=`                                                  |
| Acceso    | Público                                                                        |
| Reglas    | RN-02, RN-19                                                                   |
| Frontend  | [HU-02 en el e-com](../../../../../e-com/docs/epics/catalogo/stories/HU-02.md) |

## Historia

> **Como** e-commerce de Nativa 360, **quiero** obtener el listado paginado de
> productos activos con su precio vigente y disponibilidad, **para** mostrar
> el catálogo.

## Escenarios

```gherkin
Característica: API del catálogo de productos

  Antecedentes:
    Dado que hay 30 productos activos y 5 inactivos

  Escenario: Positivo – listado paginado
    Cuando se hace GET /productos?page=1&limit=20
    Entonces la respuesta es 200 con 20 productos activos
    Y incluye el total de productos (30) y de páginas (2)

  Escenario: Positivo – precio con promoción vigente
    Dado que "Vitamina C 1000 mg" tiene una promoción vigente del 10 %
    Cuando se hace GET /productos
    Entonces ese producto trae su precio normal y su precio con descuento

  Escenario: Negativo – los inactivos no se devuelven
    Cuando se hace GET /productos sin filtros
    Entonces ninguno de los 5 productos inactivos viene en la respuesta

  Escenario: Error – la base de datos no responde
    Dado que la base de datos no está disponible
    Cuando se hace GET /productos
    Entonces la respuesta es 503 con el formato de error estándar

  Esquema del escenario: Validación – parámetros de paginación
    Cuando se hace GET /productos?page=<page>&limit=<limit>
    Entonces la respuesta es <codigo>

    Ejemplos:
      | page | limit | codigo                       |
      | 1    | 20    | 200                          |
      | 50   | 20    | 200 con una lista vacía      |
      | 0    | 20    | 400                          |
      | 1    | 500   | 400                          |
      | abc  | 20    | 400                          |
```
