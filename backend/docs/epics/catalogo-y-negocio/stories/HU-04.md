# HU-04 (API) — Consultar el detalle de un producto

| Campo     | Valor                                                                          |
| --------- | ------------------------------------------------------------------------------ |
| Endpoints | `GET /productos/:id`                                                           |
| Acceso    | Público                                                                        |
| Reglas    | RN-02                                                                          |
| Frontend  | [HU-04 en el e-com](../../../../../e-com/docs/epics/catalogo/stories/HU-04.md) |

## Historia

> **Como** e-commerce de Nativa 360, **quiero** obtener el detalle completo
> de un producto, **para** mostrarlo en su página.

## Escenarios

```gherkin
Característica: API del detalle de un producto

  Escenario: Positivo – producto activo
    Dado que existe el producto activo con id 12
    Cuando se hace GET /productos/12
    Entonces la respuesta es 200 con nombre, descripción, imagen, precio, categoría y existencias

  Escenario: Negativo – producto inactivo
    Dado que el producto con id 13 está inactivo
    Cuando se hace GET /productos/13
    Entonces la respuesta es 404

  Escenario: Negativo – producto inexistente
    Cuando se hace GET /productos/99999
    Entonces la respuesta es 404

  Escenario: Error – la base de datos no responde
    Dado que la base de datos no está disponible
    Cuando se hace GET /productos/12
    Entonces la respuesta es 503 con el formato de error estándar

  Escenario: Validación – identificador inválido
    Cuando se hace GET /productos/abc
    Entonces la respuesta es 400
```
