# Épica: API de catálogo y negocio

> **Como** frontend de Nativa 360 (landing, e-commerce y admin), **quiero**
> una API que entregue y administre la información del negocio y los
> productos, **para** mostrar siempre datos correctos y consistentes en todo
> el sitio.
