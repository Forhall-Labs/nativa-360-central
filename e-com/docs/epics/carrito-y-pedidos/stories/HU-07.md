# HU-07 — Coordinar un pedido mediante WhatsApp

| Campo      | Valor                                                                             |
| ---------- | --------------------------------------------------------------------------------- |
| Usuario    | Cliente y personal autorizado                                                     |
| Prioridad  | Alta                                                                              |
| Riesgo     | Medio                                                                             |
| Sprint     | 4 · Carrito y pedidos                                                             |
| Puntos     | Por determinar                                                                    |
| Requisitos | MO-15                                                                             |
| Reglas     | RN-10, RN-11, RN-13, RN-14                                                        |
| API        | Solo lee el número de WhatsApp (`GET /negocio`). No hay integración con WhatsApp. |

## Historia

> **Como** cliente, **quiero** abrir WhatsApp con los datos de mi pedido ya
> escritos, **para** coordinar la disponibilidad, el pago y la entrega con el
> personal de Nativa 360.

## Escenarios

```gherkin
Característica: Coordinar un pedido mediante WhatsApp

  Antecedentes:
    Dado que el negocio tiene configurado su número de WhatsApp
    Y que el cliente registró el pedido "N360-0042" con 2 unidades de "Omega 3" por ₡16 000

  Escenario: Positivo – abrir WhatsApp con el pedido
    Dado que el cliente está en la pantalla del pedido registrado
    Cuando presiona "Coordinar por WhatsApp"
    Entonces se abre WhatsApp con el número del negocio
    Y el mensaje ya escrito incluye el código "N360-0042", los productos y el total estimado
    Y el cliente decide si lo envía

  Escenario: Positivo – volver a coordinar desde "Mis pedidos"
    Dado que el cliente cerró la pantalla del pedido
    Cuando abre "N360-0042" desde "Mis pedidos"
    Entonces ve el botón "Coordinar por WhatsApp"

  Escenario: Negativo – el sistema no envía mensajes ni confirma pagos
    Dado que el cliente abrió WhatsApp desde su pedido
    Cuando envía una foto del comprobante de pago
    Entonces el pedido sigue en estado "pendiente"
    Y solo cambia cuando el personal verifica el pago en el panel

  Escenario: Error – el número de WhatsApp no está disponible
    Dado que la API no devuelve el número de WhatsApp
    Cuando el cliente ve la pantalla del pedido registrado
    Entonces no se muestra el botón "Coordinar por WhatsApp"
    Y ve el teléfono de respaldo del negocio con el código de su pedido

  Esquema del escenario: Validación – el mensaje se arma bien con cualquier nombre de producto
    Dado que el pedido incluye el producto "<producto>"
    Cuando el cliente presiona "Coordinar por WhatsApp"
    Entonces el mensaje de WhatsApp muestra "<producto>" sin caracteres raros

    Ejemplos:
      | producto                   |
      | Té de jengibre & limón     |
      | Vitamina D3 + K2           |
      | Aceite 100 % de coco       |
      | Miel de abeja "pura"       |
```
