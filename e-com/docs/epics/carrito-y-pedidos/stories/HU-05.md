# HU-05 — Agregar productos al carrito

| Campo      | Valor                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------- |
| Usuario    | Cliente                                                                                                 |
| Prioridad  | Alta                                                                                                    |
| Riesgo     | Medio                                                                                                   |
| Sprint     | 4 · Carrito y pedidos                                                                                   |
| Puntos     | Por determinar                                                                                          |
| Requisitos | MO-10, MO-11, MO-12, MO-13                                                                              |
| Reglas     | RN-02, RN-05                                                                                            |
| API        | No aplica: el carrito vive en el navegador. La API valida los productos al registrar el pedido (HU-06). |

## Historia

> **Como** cliente, **quiero** agregar productos a un carrito, cambiar sus
> cantidades y ver el total estimado, **para** preparar mi pedido antes de
> enviarlo.

## Escenarios

```gherkin
Característica: Agregar productos al carrito

  Antecedentes:
    Dado que existe el producto activo "Omega 3" a ₡8 000 con 10 unidades disponibles
    Y que existe el producto activo "Té de manzanilla" a ₡2 500 con 20 unidades disponibles

  Escenario: Positivo – agregar productos y ver el total
    Dado que el carrito está vacío
    Cuando el cliente agrega 2 unidades de "Omega 3"
    Y agrega 1 unidad de "Té de manzanilla"
    Entonces el ícono del carrito muestra 3 productos
    Y el carrito muestra un total estimado de ₡18 500

  Escenario: Positivo – cambiar la cantidad y eliminar un producto
    Dado que el carrito tiene 2 unidades de "Omega 3" y 1 de "Té de manzanilla"
    Cuando el cliente sube "Omega 3" a 3 unidades
    Y elimina "Té de manzanilla"
    Entonces el carrito muestra solo "Omega 3" con un total estimado de ₡24 000

  Escenario: Positivo – el carrito se conserva al volver
    Dado que el cliente agregó productos al carrito
    Cuando cierra la pestaña y vuelve a entrar al comercio electrónico
    Entonces el carrito tiene los mismos productos y cantidades

  Escenario: Negativo – producto agotado
    Dado que "Omega 3" no tiene existencias
    Cuando el cliente intenta agregarlo al carrito
    Entonces el botón "Agregar al carrito" está desactivado
    Y el producto no se agrega

  Escenario: Negativo – un producto del carrito se deshabilitó
    Dado que el carrito tiene "Té de manzanilla"
    Y que el personal deshabilitó ese producto
    Cuando el cliente abre el carrito
    Entonces "Té de manzanilla" aparece marcado como "Ya no está disponible"
    Y no se suma al total ni se incluye en el pedido

  Escenario: Error – no se pueden actualizar los precios
    Dado que el carrito tiene productos
    Y que la API no responde
    Cuando el cliente abre el carrito
    Entonces ve sus productos con el último precio conocido
    Y un aviso de que los precios se confirmarán al registrar el pedido

  Esquema del escenario: Validación – cantidades permitidas
    Dado que "Omega 3" tiene 10 unidades disponibles
    Cuando el cliente cambia la cantidad de "Omega 3" en el carrito a <cantidad>
    Entonces <resultado>

    Ejemplos:
      | cantidad | resultado                                                        |
      | 5        | la cantidad queda en 5                                           |
      | 0        | se le pregunta si quiere eliminar el producto del carrito        |
      | 11       | la cantidad queda en 10 y ve "Solo hay 10 unidades disponibles"  |
      | -1       | la cantidad no cambia                                            |
```
